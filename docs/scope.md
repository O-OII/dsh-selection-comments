# Scope and alternatives / 定位与同类项目

This is a lightweight DSH annotation plugin, not the first one. Other projects include [dsh-annotation](https://github.com/omdsh-dev/dsh-annotation), [dsh-quote-annotate](https://github.com/wangwei-wade/dsh-quote-annotate), and [dsh-inline-comments](https://github.com/zenvertao/dsh-inline-comments). Review their current documentation rather than treating this list as a feature ranking or compatibility test.

This project's choices are a compact quote+comment semantic entity, numbered passage anchors, no extra composer footer, and explicit browser-tab recovery. It does not try to be a permanent notes database, cloud sync service, cross-tab reference transfer mechanism or session-fork annotation mapper. Layout ownership must be unambiguous; unsupported panes fail closed. See [privacy and limitations](privacy.md) and the [verification matrix](compatibility.md).

本项目不是首个 DSH 注释插件；同类链接如上，应以各项目当前文档为准，不作为功能排名或兼容性实测。这里选择紧凑的原文+注释实体、编号锚点、不增加 composer footer 和明确的标签页级恢复，而非永久笔记、云同步、跨标签页传递或 fork 迁移。正文归属无法确认时不操作，具体边界见[隐私说明](privacy.md)与[验证矩阵](compatibility.md)。
